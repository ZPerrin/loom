# Weft

## Scope

The universe is every markdown file outside tests/: the managed set, the six skills, and the plan.
Skills are docs with no frontmatter; they are read and cut and never stamped. Fixtures are test
data and stay wrong on purpose. Manifest description strings are read for cohesion and edited only
when they contradict the front doors. When the project is loom, its mechanics are the project;
"never loom's mechanics" means no narration of the pass itself.

## Off limits

A line under Invariants; change-log lines; an experiment under warp.md's Experiments (trim the
wording, delete none); the plan's order, exit lines, and statuses; the mermaid graphs until item 8
rules on them. A normative sentence keeps its promise, and a wording edit to a requirement,
scenario, or Non-goal gets a change-log line ending `-> edited`.

## Cuts

A whole-set pass cuts what fails on its own and flags the rest; the operator rules the flagged
blocks and a second cut follows the ruling. Blocks in the operator's voice (the ethos's Genesis,
the roadmap's Ideas) are flagged, never cut. A skill line that also stands in a reference the skill
loads is cut from the skill and listed as a behavior change. When a skill's default contradicts a
repo override, the skill line is narrowed until both are true, and the change is listed. Skill
prose that names a script's output is read against the script.
